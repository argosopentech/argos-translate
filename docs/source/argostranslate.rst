argostranslate package
======================

Common entry points
---------------------

Use :func:`argostranslate.translate.translate` for a string and
:func:`argostranslate.translate.get_installed_languages` to discover languages.
Use :func:`argostranslate.package.get_available_packages` and
:meth:`argostranslate.package.AvailablePackage.install` to install models.
See :doc:`examples` for a complete workflow and a missing-language check.

The module listing also includes implementation helpers; most applications only
need the ``package`` and ``translate`` modules. The GUI is maintained separately
(see :doc:`gui`).
